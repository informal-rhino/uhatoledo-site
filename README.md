# uhatoledo.org

Website for UHA Toledo — a chapter of [Universal Health Aid](https://www.universal-health-aid.org).

Plain HTML + one stylesheet (`assets/site.css`), published with GitHub Pages at https://uhatoledo.org.

**To edit:** open any `.html` file on GitHub, click the pencil, change the text, and commit. The site updates in about a minute.
Photos live in `assets/img/`. Rebuilt in November 2026 from the 2023 Wayback Machine archive; see the "Chapter sites – changes from the archives" doc in Drive for what changed.
